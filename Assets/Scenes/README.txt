Scenes are generated, not hand-authored.

After opening the project in Unity 2022.3.48f1, run the menu:

    SHIFT > Setup Project (Scene + Bootstrap + WebGL)

It creates Main.unity here with a camera and a Bootstrap object, assigns the
8 level files, and registers the scene in Build Settings. Then press Play.
See ../SETUP.md in the project root for the full walkthrough.
